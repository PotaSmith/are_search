================================================================
AreSearch セットアップガイド
================================================================

このガイドは、AreSearch を Rails アプリへ導入し、最初の index を作成して検索するまでを扱う。
IndexTarget と sync stage の設計は guide_index_targets_and_stages.txt、検索オプションは guide_usage.txt、
運用操作は guide_operations.txt、機能の詳細は guide_reference.txt を参照する。


# 1. インストール
================================================================

Gemfile に追加する。

    gem 'are_search', path: '/path/to/are_search'

インストールと初期ファイル生成を実行する。

    bundle install
    rails generate are_search:install
    rails db:migrate

主に以下のファイルが生成される。

    config/initializers/are_search.rb
    config/are_search_searchable.rb
    db/migrate/xxxxxxxxxxxxxx_create_are_search_tables.rb

AreSearch は標準のDB固有処理として PostgreSQL 向け実装を使用する。
DB固有処理は AreSearch.database_specific で差し替え可能。

are_search_sync_requests、are_search_sync_locks は検索対象モデルと同じデータベースに作成する。
通常の保存・touch・削除でDB更新と同期要求を同じトランザクションに含めるため、
are_search_sync_requests を別データベースへ分離しない。


# 2. イニシャライザ
================================================================

config/initializers/are_search.rb で searchable_class_setting の設定ファイルを読み込み、
Elasticsearch クライアントと index_prefix を設定する。

    load Rails.root.join("config", "are_search_searchable.rb")

    AreSearch.setup(
        index_prefix: "#{ConfVars.get(:are_search, :index_prefix)}_#{Rails.env}"
    ) do
        Elasticsearch::Client.new(
            url:      ConfVars.get(:are_search, :url),
            user:     ConfVars.get(:are_search, :user),
            password: ConfVars.get(:are_search, :password),
            adapter: :net_http,
            transport_options: {
                request: {
                    open_timeout: 2,
                    timeout:      10,
                },
                ssl: { verify: false },
            },
            ca_fingerprint: ConfVars.get(:are_search, :ca_fingerprint),
            log: Rails.env.development?,
            logger: logger,
        )
    end

index_prefix は環境間で重複しない値にする。

index target の alias 名は以下の形式になる。

    {index_prefix}__{are_search_ar_table_name}__{index_target_name}

物理 index 名は alias 名の後ろへ timestamp を追加する。

    {index_prefix}__{are_search_ar_table_name}__{index_target_name}__{timestamp}

are_search_ar_table_name は既定では Active Record の table_name を使用する。
index_prefix、are_search_ar_table_name、index_target_name の名前制約は guide_reference.txt を参照する。
index_prefix に空文字列は指定できない。

setup ブロックは Elasticsearch::Client のインスタンスを返す。
任意設定は guide_reference.txt を参照する。

Elasticsearch::Client.new の設定:

    https://www.elastic.co/docs/reference/elasticsearch/clients/ruby/basic-config
    https://www.elastic.co/docs/reference/elasticsearch/clients/ruby/advanced-config


# 3. モデル定義とIndexTarget設定
================================================================

検索対象モデルへ AreSearch::Searchable を include し、設定から参照するメソッドを定義する。

    class Article < ApplicationRecord
        include AreSearch::Searchable

        def self.default_properties
            {
                id:         { type: "long" },
                user_id:    { type: "long" },
                updated_at: { type: "date" },
                title: {
                    type:            "text",
                    analyzer:        "cjk_index_analyzer",
                    search_analyzer: "cjk_search_analyzer",
                },
                body: {
                    type:            "text",
                    analyzer:        "cjk_index_analyzer",
                    search_analyzer: "cjk_search_analyzer",
                },
                status: { type: "keyword" },
            }
        end

        def default_indexable?
            true
        end

        def default_search_data
            {
                id:         id,
                user_id:    user_id,
                updated_at: updated_at,
                title:      title,
                body:       body,
                status:     status,
            }
        end
    end

config/are_search_searchable.rb で、モデルごとの IndexTarget と sync stage を設定する。
生成される config/initializers/are_search.rb の先頭からこのファイルを読み込む。

    AreSearch.searchable_class_setting = {
        "Article" => {
            default: {
                settings: {
                    max_result_window: 2_000,
                },
                mappings: {},
                properties_method: :default_properties,
                indexable_method: :default_indexable?,
                stages: {
                    "default" => {
                        data_method: :default_search_data,
                        enqueue: true,
                        after_commit: true,
                    },
                },
            },
        },
    }

properties_method はクラスメソッド、indexable_method と data_method は引数なしのインスタンスメソッドを指定する。
stages の enqueue は保存時に SyncRequest を作るか、after_commit は commit 後に同期を開始するかを指定する。

設定の詳細は guide_reference.txt、IndexTarget と sync stage の使い分けは
guide_index_targets_and_stages.txt を参照する。


# 4. モデル設定を確認する
================================================================

AreSearch.searchable_class_setting は Rails の after_initialize で検査される。
さらに Searchable を include している全モデルと STI 子クラスの設定メソッドを確認する。

    bundle exec rake are_search:check_all_models

正常な場合は以下を出力する。

    全モデル正常

初回 reindex 前にこの確認を行う。


# 5. 初回 reindex
================================================================

index 操作を実行する実行環境では以下を有効にする。

    AreSearch.index_operation_enabled = true

初回 index を作成する。

    Article
        .are_search_index_target(:default)
        .are_search_reindex(stage_position: :first)

初回 reindex 前の検索結果は search_failure_mode に依存する。
複数 target がある場合は target ごとに実行する。

index_operation_enabled と reindex の詳細は guide_reference.txt と guide_operations.txt、
stage の選択方法は guide_index_targets_and_stages.txt を参照する。


# 6. 最初の検索
================================================================

    article_index = Article.are_search_index_target(:default)

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
        ],
    )

    result.records.each do |article|
        puts article.title
    end

ページネーションを指定する場合。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
        ],
        page:         params[:page],
        per_page:     20,
    )

    @articles = result.records
    @total = result.records.total_count

検索オプションと検索結果は guide_usage.txt を参照する。


# 7. 運用サンプルを生成する
================================================================

利用側で編集して使用する運用ファイルのサンプルを生成する。

    rails generate are_search:sample

以下のファイルが生成される。

    tmp/are_search/sample/are_search_run_sync_requests.rake.sample
        SyncRequest を定期回収する rake task のサンプル。

    tmp/are_search/sample/are_search_sync_limit_alert.rake.sample
        SyncRequest の同期停止候補をメール通知する rake task のサンプル。

    tmp/are_search/sample/are_search_sync_request_boundary.rake.sample
        BoundaryTarget を使用した 同期処理のrakeのサンプル。

    tmp/are_search/sample/are_search_bulk_index.rb.sample
        BulkIndexer を実行する Ruby ファイルのサンプル。

    tmp/are_search/sample/are_search_bulk_index.sh.sample
        BulkIndexer を起動する shell ファイルのサンプル。

rake task の配置、設定、実行方法は guide_operations.txt を参照する。
BulkIndexer サンプルの配置、設定、実行方法は guide_bulk_indexer.txt を参照する。
