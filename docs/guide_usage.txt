================================================================
AreSearch 使い方ガイド
================================================================

このガイドは、検索方法、検索オプション、SearchResult の扱いを説明する。
導入は guide_setup.txt、IndexTarget と sync stage は guide_index_targets_and_stages.txt、
運用操作は guide_operations.txt、設定値は guide_reference.txt を参照する。


# 1. 検索する
================================================================

複数targetを含む検索は AreSearch::Searcher.search を使用する。

    article_index = Article.are_search_index_target(:default)

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "検索ワード",
                fields:       [:title, :body],
            },
        ],
    )

戻り値は AreSearch::SearchResult。

単一targetでは IndexTarget#are_search_search をショートハンドとして使用できる。

    result = article_index.are_search_search(
        "検索ワード",
        fields: [:title, :body],
    )

単一targetのショートハンドでは relation を指定できる。


# 2. 標準検索
================================================================

query_type は省略できる。
query_string が空文字列または空白だけの場合、その条件は検索に使用されない。

検索条件が1件の場合。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
        ],
    )

複数条件を指定すると、すべての条件を満たす文書を検索する。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
            {
                query_string: "Elasticsearch",
                fields: {
                    title: 2.0,
                    body:  1.0,
                },
            },
        ],
    )

フィールド名だけを指定する場合は Array、フィールドごとに boost を付ける場合は Hash を使用する。

    fields: [:title, :body]

    fields: {
        title: 2.0,
        body:  1.0,
    }

text 型以外のフィールドは指定できない。


## 2-1. query_type
----------------------------------------------------------------

既定値は combined_fields。
空白で区切られた検索語を AND 条件として検索する。

    query_type: AreSearch.query_type_combined_fields

simple_query_string を使用する例。

    queries: [
        {
            query_string: 'Ruby + (Rails | Elasticsearch) -"Java VM"',
            fields:       [:title, :body],
            query_type:   AreSearch.query_type_simple_query_string,
        },
    ]

使用できる主な検索式。

    Ruby Rails
        default_operatorがANDのため、両方を含む

    Ruby + Rails
        AND

    Ruby | Rails
        OR

    Ruby -Rails
        NOT

    Ruby + (Rails | Elasticsearch)
        括弧による優先順位

    "Ruby on Rails"
        フレーズ検索

query_string は変換せず Elasticsearch へ渡す。
指定の詳細は Elasticsearch の simple_query_string のドキュメントを参照する。

    AreSearch.query_type_combined_fields
    AreSearch.query_type_simple_query_string


# 3. More Like This
================================================================

mlt は指定したレコードに似たレコードを検索する。
queries、sort とは同時に指定できない。

    result = AreSearch::Searcher.search(
        [article_index],
        mlt: {
            fields: [:title, :body],
            like: {
                instance:     article,
                index_target: article_index,
            },
            min_term_freq:        1,
            min_doc_freq:         2,
            max_query_terms:      20,
            min_word_length:      2,
            minimum_should_match: "30%",
            boost_terms:          1.5,
        },
    )

mlt.fields と mlt.like は必須。

mlt.fields は text または keyword 型フィールドを Symbol の Array で指定する。
検索対象側で同名フィールドが別の型として定義されている場合は使用できない。

基準に使う mlt.like.index_target では、指定フィールドを _source または store: true から取得できる必要がある。

    instance
        基準レコード。

    index_target
        基準レコードが保存されている IndexTarget。
        instance から同じtargetを解決したときに、同じElasticsearch aliasを指す必要がある。

_source から取得する例。

    _source: {
        includes: [:title],
    },
    properties: {
        title: { type: "text" },
    }

store: true を使用する例。

    properties: {
        body: {
            type:  "text",
            store: true,
        },
    }

mlt.fields と like 以外の Symbol key は Elasticsearch の More Like This パラメーターとして渡す。
min_term_freq、min_doc_freq、max_query_terms の既定値はそれぞれ 2、5、25。


# 4. Raw body 検索
================================================================

複雑な検索では raw_body に Elasticsearch の Query DSL を指定できる。

    body = {
        track_total_hits: true,
        query: {
            bool: {
                must: [
                    { match: { title: "Rails" } },
                ],
            },
        },
    }

    result = AreSearch::Searcher.search(
        [article_index],
        raw_body: body,
        page:     1,
        per_page: 20,
    )

raw_body と同時に使用できる AreSearch 側のオプション。

    :model_relations
    :page
    :per_page
    :build_model_bool
    :enable_runtime_mappings
    :dump_body

from と size は page / per_page から設定する。
その他の指定は Elasticsearch へ渡す。

build_model_bool: true を指定すると検索対象モデルの条件を追加する。
raw_body には query.bool が必要。

    result = AreSearch::Searcher.search(
        [article_index],
        raw_body: {
            query: {
                bool: {
                    must: [
                        { match: { title: "Rails" } },
                    ],
                },
            },
        },
        build_model_bool: true,
    )

正確な総件数が必要な場合は track_total_hits: true を指定する。
生レスポンスは result.raw_response で取得する。


# 5. 共通オプション
================================================================

標準検索と More Like This で使用できる共通オプション。

    :runtime_mappings
    :where
    :where_not
    :where_or
    :aggs
    :page
    :per_page
    :model_relations
    :highlight
    :response
    :enable_runtime_mappings
    :dump_body

sort は標準検索でのみ使用できる。

フィールド指定の主な条件。

    queries.fields
        text フィールド。

    mlt.fields
        text または keyword フィールド。
        基準側でも同名フィールドを取得できる必要がある。

    highlight.fields
        text または keyword フィールド。

    where / where_not / where_or
        text 型ではないフィールド。

    sort
        すべての検索対象targetに存在する非 text フィールド。

    aggs
        text 型ではないフィールド。

runtime_mappings で定義したフィールドは type に応じて同じ条件で使用できる。
response.source、response.fields、response.stored_fields、response.docvalue_fields は mapping との照合を行わない。


# 6. runtime_mappings
================================================================

検索時だけ使用する runtime field を指定できる。

    result = AreSearch::Searcher.search(
        [article_index],
        runtime_mappings: {
            runtime_status: {
                type: "keyword",
                script: {
                    source: "emit('published')",
                },
            },
        },
        queries: [
            {
                query_string: "Rails",
                fields:       [:title],
            },
        ],
        where: {
            runtime_status: {
                term: "published",
            },
        },
        response: {
            fields: ["runtime_status"],
        },
        enable_runtime_mappings: true,
    )

runtime_mappings を使用する場合は enable_runtime_mappings: true を指定する。
dump_body: true の場合はこの指定は不要。

raw_body検索では runtime_mappings を raw_body 内へ指定し、
enable_runtime_mappings: true は Searcher.search のトップレベルへ指定する。


# 7. response で追加フィールドを取得する
================================================================

検索結果へ追加で含める _source と fields 系の取得方法を指定できる。

    response: {
        source: [
            "title",
            "payload.display.*",
        ],
        fields: [
            "runtime_status",
            "published_at",
        ],
        stored_fields: [
            "body",
        ],
        docvalue_fields: [
            "status",
            "user_id",
        ],
    }

    source
        Elasticsearch の _source から取得する。
        index の _source に保存されていない値は含まれない。

    fields
        Elasticsearch の fields から取得する。
        通常fieldは _source に保存されている必要がある。
        runtime field は _source に保存されていなくても取得できる。

    stored_fields
        mapping で store: true のフィールドを取得する。

    docvalue_fields
        keyword、数値、date等の doc values を取得する。

fields、stored_fields、docvalue_fields で返された値は records_with_hit の hit[:fields] から取得する。

raw_body検索では response を使用せず、_source、fields、stored_fields、docvalue_fields を body へ直接指定する。


# 8. 外部入力を検索条件に使う
================================================================

外部入力として指定できる値。

    queries の query_string
    where / where_not / where_or の条件値
    page

標準の search_param_policy では、queries.query_string は2048文字まで、
where系の term / terms / range は文字列化した長さが256文字までの場合に許可する。
制限は AreSearch.search_param_policy で差し替えできる。

値が制約に合わない場合、search_failure_mode が :empty_result なら STATUS_PARAMS_INVALID の空結果を返し、
:raise なら AreSearch::InvalidSearchOption を送出する。

検索条件が1件の場合。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: params[:q],
                fields:       [:title, :body],
            },
        ],
    )

検索条件が複数ある場合。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: params[:title_q],
                fields:       [:title],
            },
            {
                query_string: params[:body_q],
                fields:       [:body],
            },
        ],
    )

絞り込み。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: params[:q],
                fields:       [:title, :body],
            },
        ],
        where: {
            status: {
                term: params[:filter_value],
            },
        },
    )

並び順、ページング。

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: params[:q],
                fields:       [:title, :body],
            },
        ],
        sort:         :updated_at,
        page:         params.fetch(:page, 1).to_i,
        per_page:     20,
    )


# 9. where / where_not / where_or
================================================================

    where: {
        status: {
            term: "published",
        },
        user_id: {
            terms: [1, 2, 3],
        },
        price: {
            range: {
                gte: 1_000,
                lte: 5_000,
            },
        },
    }

同じ field の条件を複数指定する場合は Array を使用する。

    where: [
        {
            price: {
                range: {
                    gte: 1_000,
                },
            },
        },
        {
            price: {
                range: {
                    lte: 5_000,
                },
            },
        },
    ]

    where_not: {
        status: {
            terms: ["draft", "deleted"],
        },
    }

    where_or: [
        {
            status: {
                term: "featured",
            },
        },
        {
            user_id: {
                terms: [1, 2, 3],
            },
        },
    ]

text 型フィールドは指定できない。
where はすべて一致、where_not は除外、where_or はいずれか1件一致。

term、terms、range の値は String、Integer、Float、true、false。
terms は Array、range は1件以上の Hash で指定する。terms には空Arrayも指定できる。
日付は Elasticsearch が解釈できる String または Integer で指定する。


# 10. model_relations / relation
================================================================

検索結果を ActiveRecord から取得する Relation を対象モデルごとに指定できる。

    result = AreSearch::Searcher.search(
        [
            Article.are_search_index_target(:default),
            Document.are_search_index_target(:default),
        ],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
        ],
        model_relations: {
            Article => Article
                .where(status: "published")
                .includes(:user, :tags),
            Document => Document
                .where(visible: true)
                .includes(:author),
        },
    )

単一 target のショートハンドでは relation を使用する。

    result = article_index.are_search_search(
        "Rails",
        fields: [:title, :body],
        relation: Article
            .where(status: "published")
            .includes(:user, :tags),
    )

Relation の条件に合わない結果と、DB に存在しない結果は除外される。
includes、joins なども Relation に指定できる。


# 11. page / per_page
================================================================

    result = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
        ],
        page:         2,
        per_page:     20,
    )

result.records は Kaminari の paginate ヘルパーに対応する。

    paginate result.records

主なページ情報。

    result.records.page
    result.records.per_page
    result.records.total_count
    result.records.es_total_count
    result.records.pagination_total_count
    result.records.total_pages

取得範囲の上限は target の max_result_window。複数targetでは最小値を使用する。
開始位置が max_result_window 以上になる指定は検索パラメータ不正になる。

件数の用途。

    es_total_count
        Elasticsearch が返した検索ヒット総数。

    total_count
        ActiveRecordへ復元できなかった現在ページの件数を差し引いた表示用総件数。

    pagination_total_count
        max_result_window を考慮したページング可能件数。

total_pages、previous_page、next_page、out_of_range? は pagination_total_count を使用する。


# 12. sort
================================================================

sort は標準検索で使用できる。

    sort: :updated_at

    sort: {
        updated_at: :desc,
        id:         :desc,
    }

Hash はキーの記述順を優先順位として使用する。
フィールドには Elasticsearch の特別な値 _score と _doc も指定できる。

sort の値は String または Symbol。


# 13. aggs
================================================================

非textフィールドを aggregation に使用する。
フィールド名だけを指定する場合は Array を使用する。

    aggs: [:status, :category]

各フィールドは同名の terms aggregation として扱われ、size には AreSearch.default_aggs_size を使用する。

集計名やオプションを指定する場合は Elasticsearch 形式の Hash を使用する。

    aggs: {
        status_count: {
            terms: {
                field: :status,
                size: 20,
            },
        },
        score_ranges: {
            range: {
                field: :score,
                ranges: [
                    { to: 1.0 },
                    { from: 1.0, to: 2.0, key: "middle" },
                    { from: 2.0 },
                ],
            },
        },
    }

aggregation body の field は必須。
その他の Elasticsearch aggregation オプションはその形式で指定する。

    result.aggs(:status_count).each do |name, count|
        puts "#{name}: #{count}"
    end

result.aggs(name) の簡易結果。

    key がある
        [[key, doc_count], ...]
        key_as_string がある場合は key の代わりに使用する。

    key がない
        [doc_count, ...]

簡易結果で扱えない aggregation は result.raw_response を参照する。


# 14. highlight
================================================================

highlight は検索結果の一致部分を返す。
fields は必須で、text または keyword 型フィールドを指定する。

フィールド名だけを指定する場合。

    highlight: {
        fields: [:title, :body, :status],
    }

フィールド別オプションを指定する場合。

    highlight: {
        fields: {
            body: {
                fragment_size:       200,
                number_of_fragments: 3,
            },
            status: {
                number_of_fragments: 0,
            },
        },
        type:                "unified",
        require_field_match: false,
    }

fields に指定するフィールドは 検索元となるデータの設定では store: true または _source 含める。

    body: {
        type:  "text",
        store: true,
    }

fields 以外は Elasticsearch の highlighting オプションとして指定する。


# 15. dump_body
================================================================

検索を実行せず、AreSearch が組み立てた body を確認する。

    body = AreSearch::Searcher.search(
        [article_index],
        queries: [
            {
                query_string: "Rails",
                fields:       [:title, :body],
            },
        ],
        where: {
            status: {
                term: "published",
            },
        },
        dump_body: true,
    )

    pp body

raw_body検索では page、per_page、build_model_bool を反映した body を返す。


# 16. SearchResult
================================================================


## 16-1. status
----------------------------------------------------------------

検索の終了状態を確認する。

    result.status

定数で判定する。

    if result.status == AreSearch::SearchResult::STATUS_PARAMS_INVALID
        # 外部入力値が不正、または SearchBodyPolicy に拒否された場合の処理
    end

戻り値。

    AreSearch::SearchResult::STATUS_OK
        値は :ok。
        Elasticsearch へ検索を実行した。
        検索結果が0件の場合もこのstatusになる。

    AreSearch::SearchResult::STATUS_PARAMS_INVALID
        値は :params_invalid。
        検索パラメータまたは検索bodyが許可されず、空結果を返した。

    AreSearch::SearchResult::STATUS_INDEX_NOT_FOUND
        値は :index_not_found。
        検索対象 index または MLT の基準indexが存在せず、空結果を返した。


## 16-2. records
----------------------------------------------------------------

ActiveRecord のレコードを検索順で返す。

    result.records


## 16-3. records_with_hit
----------------------------------------------------------------

ActiveRecord のレコードと対応する Elasticsearch hit を検索順で取得する。

    result.records_with_hit.each do |record, hit|
        puts record.title
        puts hit[:index]
        puts hit[:id]
        puts hit[:index_target_name]
        puts hit[:source][:title]
        puts hit[:fields][:runtime_status]

        hit[:highlight].each do |field_name, fragments|
            fragments.each do |fragment|
                puts "#{field_name}: #{fragment}"
            end
        end
    end

hit の主なキー。

    :index
        Elasticsearch が返した _index。

    :id
        Elasticsearch が返した _id。

    :source
        Elasticsearch が返した _source。

    :fields
        response.fields、response.stored_fields、response.docvalue_fieldsで取得した値。

    :highlight
        Elasticsearch が返した highlight。

    :index_target_name
        レコードを復元した IndexTarget の index_target_name。

1件でも _source が無い場合、ActiveRecordへの復元は行わず records と records_with_hit は空になる。
Elasticsearch のレスポンスは raw_response に残る。


## 16-4. raw_response
----------------------------------------------------------------

Elasticsearch の生レスポンスを返す。

    result.raw_response
